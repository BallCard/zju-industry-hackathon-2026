# 评分对照与自检清单

## 初赛（本阶段：2026-10-18 17:00 前）
材料：GitHub 链接 + 魔搭链接 + 作品说明书。评审看：是否准确理解题目、是否形成自研 Agent 方案、是否实现核心流程、材料能否清楚证明实际完成情况。
- [ ] GitHub 含源码、README、安装运行方法、依赖说明；**无任何 API Key / Client ID**
- [ ] 魔搭（ModelScope）页面可访问，信息与 GitHub、说明书一致
- [ ] 说明书：功能讲解 + 优秀运行结果 + 架构 + 提示词设计 + ima 调用方式 + 部署步骤 + 已知限制；**至少一组可辨认的运行结果**
- [ ] 代码可运行，非空壳/PPT/静态页；无抄袭、伪造
- [ ] 评审期内无需额外授权即可访问所有链接
- 不进复赛：链接空/失效、无运行结果、仅概念或静态页、ima 直接生成最终软文而自研仅转发、抄袭伪造
