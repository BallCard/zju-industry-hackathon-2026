# 契约 C3：知识库结构（`apps/pc-studio/data/kb/`，与 ima 共享库同构）

知识库作为 PC Studio 的只读资料快照，当前按用户明确授权随仓库发布；不得在代码中修改内容或另行扩散未授权副本。统计：1522 文件（1365 md、112 图），P1 322 / P2 101 / P3 178 / P4 20 / P5 135 / P6 409。

| 目录 | 用途 | Agent 怎么用 |
| --- | --- | --- |
| `00-建库规范/` | 事实分级、命名、审核、**智能体规则（06）**、术语 | 提示词与拒答边界的依据，必读 |
| `P1-产品参数库/<类>/<型号>/` | `产品事实.md` `卖点与限制.md` `图片索引.csv` `来源清单.csv` `images/` | **事实与图片的主来源**。图片只能经 `图片索引.csv` 登记的文件，且按“产品型号”列匹配 |
| `P1/04-华为商城销售款式`、`08-官方公开价格快照` | 配置/价格快照 | 价格仅可引用快照并带“类型/时间/条件”；无记录一律不报价 |
| `P2-卖点话术库` | 按渠道/人群/型号角色话术 | 策略参考，不当事实源 |
| `P6-营销素材库` | 平台模板(02)、合规(08)、按型号平台(09)、完整软文成稿(11)、官方传播案例(12/13) | 平台规则、合规清单、风格参考（**不得照抄成稿**，否则可能判抄袭） |
| `P7` 常见问题 · `P8` 客户场景 | 场景与追问素材 | 场景解析、追问设计 |
| `P3-竞品资料库` | 竞品事实 | 对比必须有依据，禁止无依据贬低 |
| `P4-价格政策库（机密）` | 仅字段/流程模板，无真实内部价格 | 不得据此报价 |
