# 双数据源工作流（开发与正式比赛）

## 当前决定

- 当前默认：local。使用项目上一级目录的「华为PC全板块深度知识库_v7」开发业务规则、文案、UI、导出、测试，无需消耗 ima 资料获取次数。
- 正式比赛：live。从指定共享知识库「任德耀新建华为PC知识库」实时检索，返回的内容有来源 mediaId，图片索引与型号一致。
- 本机此前实测成功4组 live 端到端案例；随后接口对 get_media_info 报错 220021，平台说明“资料获取次数已达上限，请明天再尝试”。这是平台额度限制，不代表本地代码失效。
- 不自动降级：即使ima配置了账号，默认仍选择local；用户手动选择live后若失败，直接报错，不把local假冒为ima。
- 模型API与ima独立。没有模型密钥时使用确定性业务规则生成；线上语言层可单独接入。

## 日常开发

1. 启动 npm start，访问 http://127.0.0.1:8765 。
2. 证据来源选择“本地知识库·开发演示”；此为默认值。
3. 在各个场景/平台生成图文，点证据与配图查看来源，点决策轨迹复核；导出文本会标明local来源。
4. 修改策略规则、prompt和合规检测时，执行 npm run check && npm test && npm run examples。
5. 重点修复文案自然程度、图文场景关联、临时变更能力。演示成功不代表ima库全型号验收。

## 有额度后切换正式模式

1. 确认账号与赛事ima共享知识库授权仍有效。
2. 在页面手动选择“ima官方接口·赛事模式”；无需复制TXT密钥，程序从项目外D盘ima_skill/ima.txt安全读取。
3. 先点击ima连接检查；再运行3组完整live案例，逐张查看图片能实际加载，并导出正式审计。
4. 核对所有事实/图片标记 sourceType=ima、origin=ima 并带mediaId；审核状态passed且来源正确。
5. 正式提交优先使用live运行记录和真实录屏；不得把本地案例改标签假装ima。

## 云端部署差异

已包含 data/models.json（只有10个型号名称和目录映射，不含图片或个人密钥），可以在魔搭容器中选产品。云端默认不包含本地v7事实文本，故local模式不会生成有依据的文案；云端正式展示需要用Secrets连接ima并真实复测。

## 安全与维护

- 不把TXT、ima原文、完整图片或未经授权资料放入公开Git。
- 本地事实属于资料快照，导出保留本地标签。
- 额度限制期间不反复调用 get_media_info；优先做本地测试。
- 若次日仍限制，先核实配额和恢复时间，再安排live验收。
