# 赛题：AI+华为PC营销软文智能体（华为·产业进阶赛道）

来源：赛题手册 v4（本地副本 `data/ref/handbook-v4.pdf`，未入库）。**手册为准，本文是提炼。**

## 一句话
做一套**自研 Agent**：输入「产品 + 人群 + 场景 + 发布平台」，从指定 ima 共享知识库检索华为 PC 事实与图片，输出**有依据、图文并茂、符合平台、通过合规检查**的营销软文。ima 只当资料来源，不当写作工具。

## 给谁用 / 怎么用 / 解决什么
- **用户**：华为 PC 门店导购、内容运营、渠道/政企销售。
- **怎么用**：选型号 → 选人群与场景 → 选平台（公众号/小红书/朋友圈/门店海报）→ 一键生成 → 看事实核验与合规结果 → 改稿/换平台/复制导出。
- **解决**：资料分散、型号易混、场景不准、平台不适配、图文错配、合规风险（对应手册二（三）六大痛点）。
- **自研点（评审强调）**：把门店与营销业务规则做成 Agent 的策略——同一产品，换人群/场景/平台后，**切入点、卖点顺序、结构、语气、配图数量、行动引导**必须实质变化；只改篇幅或平台名不算适配。

## 标准流程（必须体现）
场景解析 → 平台策略 → ima 资料与图片检索 → 事实点提取 → 图文编排 → 软文生成 → 事实与图片核验 → 合规检查 → 导出

## 功能最低要求（手册四（一））
| 模块 | 最低要求 |
| --- | --- |
| 账号与知识库 | 识别当前账号；找到指定共享库；**不得展示完整密钥** |
| 任务输入 | 输入产品/人群/场景/平台；信息不足时提示补充（追问） |
| 知识与图片检索 | 按型号和任务调用 ima OpenAPI；检索产品资料及图片；保留来源记录 |
| 场景与平台策略 | 识别人群、场景、内容目标和平台，形成可解释的内容策略 |
| 图文软文生成 | 输出标题、正文、行动引导、图片引用和插入位置；避免套话 |
| 事实核验 | 逐项检查产品事实；无依据必须删除或标记 |
| 合规检查 | 识别绝对化用语、虚假承诺、价格误导、无依据竞品贬低 |
| 修改与导出 | 按临时要求重新生成；支持复制或导出最终文本 |

## 统一输出格式（手册四（四），固定四段）
1. 场景判断：目标人群 / 使用场景 / 用户问题 / 内容目标 / 平台
2. 知识库依据：产品型号 / 事实点 / 资料标题
3. 图文软文：标题 / 导语 / 正文 / 行动引导；图片名称 / 来源 / 插入位置 / 图片说明
4. 核验结果：产品事实 / 图片型号 / 合规 / 待确认信息

## 平台规格（手册三（三））
| 平台 | 内容形态 | 图片 |
| --- | --- | --- |
| 公众号 | 标题、导语、分段正文、结尾行动引导 | 2–4 张，说明来源与插入位置 |
| 小红书 | 口语化标题、短段落、使用场景、话题标签 | 3–6 张，**不得伪造个人体验** |
| 门店朋友圈 | 短文案、一个核心卖点、咨询或到店引导 | 1–3 张，优先主图与场景图 |
| 门店海报 | 主标题、副标题、≤3 个核心卖点和活动说明 | 1 张主视觉，不得拉伸或错配型号 |

## 建议覆盖的场景（手册三（二））
开学季（大学新生/家长）· 职场办公 · 内容创作 · 家庭换新 · 企业采购 · 门店到访 · 新品首发 · 节日营销。**至少 2 类场景 × 2 个平台**才能满足复赛「优秀运行结果」要求。

## 系统提示词七模块（手册四（三），不得只有一句"生成软文"）
角色与任务 · 需求理解 · 平台规则 · 知识库约束（只能来自指定库）· 图片规则（必须来自 ima 且核对型号）· 生成要求 · 核验规则（无法确认则停止并提示人工确认；资料冲突停止并提示）· 合规规则

## 现场测试（复赛统一任务）
基础生成 · 换场景 · 换平台 · **干扰与修改**（易混淆型号、不完整信息、临时改稿：追问/核验/合规拦截/重新生成）

## 硬红线
- **API Key / Client ID 不得出现在**源码、README、截图、演示视频、提交文件、日志；用环境变量。泄露即作废重生成。
- 图片**不来自 ima 或型号不符 → 图片引用项计 0 分**。
- 虚构价格/补贴/销量/奖项/用户评价 → 该任务准确性与合规性计 0 分。抄袭/伪造运行记录/隐藏人工代写 → 取消成绩。
- 知识库仅限程序内部使用，不得删除、修改、对外传播资料；知识库 ID 不得外泄。

## 落地路径（路演口径）
试点：1–2 家门店 + 1 个内容运营岗 → 替换"人工查资料、找图、反复校对"流程 → 接入企业自己的 ima 知识库与素材审核流 → 扩展到直播脚本、社群答疑、产品对比、门店导购等场景（手册允许）。
