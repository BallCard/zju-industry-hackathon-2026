## 已定事项

- 10-18 · 赛道：华为·产业进阶赛道「AI+华为PC营销软文智能体」· 来自现场发布的题目。
- 10-18 · 根目录临时知识库副本放 `data/kb/`（gitignore），官方 ima skill 放 `vendor/ima-skill/`（gitignore，`scripts/fetch-ima-skill.sh` 获取）。经用户明确授权，PC Studio 的发布副本放在 `apps/pc-studio/data/kb/` 并随项目入库；凭证仍不得入库。
- 10-18 · 凭证只走环境变量/本地 `.env`；pre-commit 拦截疑似密钥与资料目录 · 手册硬红线。

- 已获用户确认：PC Studio 在同一仓库内按 `apps/pc-studio/frontend/` 与 `backend/` 分离前后端目录；暂不引入独立前端构建或拆分仓库。保持单一 Node 服务、统一 package.json 与现有 API/静态资源 URL，开发在独立任务 worktree 中完成。

- 已获用户确认：PC Studio 的 `Dockerfile` 和 `ms_deploy.json` 移至 GitHub 仓库根目录，应用源码保留在 `apps/pc-studio/`。Docker 构建上下文使用仓库根目录，根 `.dockerignore` 放行运行文件和已授权发布的 `apps/pc-studio/data/kb/`，外部私有知识库与凭证不进入镜像；修改经自检后直接合入并推送远端 main。

## 待定事项

- 语言/框架（建议：Python 3.13 + FastAPI + 单页前端；或全 TS。选队里最熟的，别讨论超过 10 分钟）。
- 大模型服务（手册允许公开大模型；选能稳定拿到 key、支持长上下文与 JSON 输出的一家）。
- 检索策略：ima `search_knowledge` 关键词检索 + 本地索引兜底？建议型号名精确定位到 P1 目录，再读该型号 `产品事实.md`、`卖点与限制.md`、`图片索引.csv`，ima 搜索补充场景与模板。
- 图片如何交给用户：UI 里直接展示 `images/` 文件，导出时带“来源/说明/位置”。
- 魔搭（ModelScope）形态：创空间（Gradio/Streamlit）最省事，需要能在评审期内无授权访问。
- 部署/演示形式：本地 + 录屏；魔搭创空间在线演示。
